# 🎬 Movie CRUD API

## 📋 Visão Geral
API REST para gerenciamento de filmes desenvolvida com FastAPI, SQLAlchemy e SQLite.

## 🔧 Tecnologias
- FastAPI
- SQLAlchemy
- SQLite
- Docker

## 💻 Requisitos
- Docker
- Docker Compose
- Python 3.9+

## 🚀 Instalação e Execução

### Clonar Repositório
```bash
git clone <url-do-repositorio>
cd movie-crud
```

### Iniciar Aplicação
```bash
docker-compose up --build
```

## 🌐 Endpoints
- `POST /api/v1/filmes`: Criar novo filme
- `GET /api/v1/filmes`: Listar todos os filmes
- `GET /api/v1/filmes/{id}`: Buscar filme específico

## 📖 Documentação
Swagger UI: http://localhost:8000/docs
